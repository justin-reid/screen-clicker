SCREEN CLICKER
What it does

Watch for an image.
Tap where you choose.

A rule watches part of the screen for an image. When it appears, the app taps the spot you picked — until you stop it.

No root, no ADB. Everything stays on your phone.

Set up

Two permissions

  • 1Accessibility service — see the screen and tap for you.
  • 2Display over other apps — keep the rule editor and panel on top.
Enable accessibility Allow over apps
Build

New script → Add rule

  • 1Search area — where to look.
  • 2Template area — the image to find, then Capture.
  • 3Click area — where to tap.
  • 4Check, then Save.

Switch app keeps the toolbar up while you bring your game forward.

Run

Run it

  • Start from the app or the floating panel.
  • First run: Android asks what to share — pick Entire screen.
  • Options ▸: Highlight matches, Show taps, runner log.

Drag / swipe the pages, or use ← → keys. The permission buttons are clickable in this mock.
